# Lapticon — PWA

Versión web instalable (PWA) de Lapticon, pensada primero para el celular. Convive con la app Flutter
(`../lapticon_app/`), que no se modifica: ambas usan el mismo backend, el mismo proyecto de Firebase y el mismo
diseño (sistema v2, `../docs/07-diseno-ux-ui.md`).

**Estado:** plan listo (decisiones tomadas el 24-oct-2026); todavía sin código. El plan detallado está en
[`../docs/10-plan-migracion-pwa.md`](../docs/10-plan-migracion-pwa.md).
